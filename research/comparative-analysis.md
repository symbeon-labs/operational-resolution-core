# Comparative Analysis

This document tracks existing fields and approaches that may overlap with Operational Resolution.

## Areas to investigate

- Entity Resolution
- Temporal Databases and Temporal Reasoning
- W3C PROV and provenance models
- Evidence Theory and uncertainty models
- Truth Maintenance Systems / ATMS
- Belief Revision
- Complex Event Processing
- Knowledge Graphs
- Digital Twins
- Event Sourcing
- EPCIS and supply-chain event standards

## Comparison questions

For each approach, ask:

1. What is its primary object of representation?
2. How does it represent conflicting claims?
3. How does it preserve evidence and provenance?
4. How does it handle temporal validity?
5. Does it resolve identity across heterogeneous identifiers?
6. Does it produce an operational state or merely represent information?
7. Does it provide a contextual resolution mechanism?

No novelty conclusion should be drawn until these comparisons are documented.
