# Experiment 003 — Contradictory Assertions

## Question

What happens when credible sources disagree?

## Test

```text
NF-e       = 100
scale      = 97
operator   = 100
ERP        = 97
```

## Observation

Selecting one value and discarding the others destroys information relevant to the operational decision.

## Result

Conflict should be representable as an operationally meaningful result.
